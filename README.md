# Peccatorum

Metroidvania 2D desarrollado en Unity como proyecto universitario.

## Características

• Exploración de un mundo interconectado con transición entre escenas
• Combates contra varios jefes (bosses)
• Soporte para mando (gamepad)
• Sistema de keybinds personalizables (el jugador puede remapear los controles)

## Tecnologías

• Motor: Unity (2D)
• Lenguaje: C#
